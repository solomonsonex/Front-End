## Assignment 3: Student Registration Form


Create a student registration form using Bootstrap 5.

### Requirements

1.  Add a heading: **Student Registration Form**.
2.  Include the following fields:
    -   First  Name
    -   Last Name 
    -   Email Address
    -   Phone Number
    -   Gender (Select)
    -   Course of Study (select )
    -   Home Address (textarea)
    -   Password
3.  Make the form responsive, occupying half the screen on desktop and
    the full width on mobile.

## General Submission Guidelines

1.  Submit all five assignments separately.
2.  Use proper HTML5 document structure.
3.  Link Bootstrap 5 CSS using the CDN.
4.  Do not use custom CSS unless very necessary.
5.  Use Bootstrap utility classes as much as possible.
6.  Ensure all pages are responsive.
7.  Use meaningful content instead of Lorem Ipsum.
8.  Test each webpage in a browser before submission.
